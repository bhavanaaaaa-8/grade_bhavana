# Student Marks Calculator
A simple Python program that accepts marks for multiple subjects, validates the input, and calculates the total marks, percentage, and grade.

## Features
- Accepts marks for multiple subjects
- Validates marks between 0 and 100
- Handles invalid inputs such as letters and symbols
- Calculates total marks
- Calculates percentage
- Assigns a grade using clear grade boundaries

## Grade Boundaries
- 90 and above → A+
- 80 and above → A
- 70 and above → B
- 60 and above → C
- 50 and above → D
- Below 50 → F

## How to Run
Run the Python file and enter the marks for each subject when prompted.

## Input Validation
If an invalid value is entered, the program displays an input failure message and asks the user to enter the marks again.
